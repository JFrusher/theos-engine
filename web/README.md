# Theos on the web

- `index.html`, `app.js`, `playground.css` — the playground: edit an argument, see the verdict, graph and diagnostics live. The checker runs in the browser as WebAssembly (`src/wasm/theos_wasm.cpp`).
- `gallery.css` — styles for the gallery pages generated by `theosc site`.
- `theos.css` — shared palette and type.
- `build-site.sh` — assembles the deployable site (playground at the root, gallery under `gallery/`).

Build locally (Emscripten 3.1.74):

```sh
emcmake cmake -B build-wasm -G Ninja -DCMAKE_BUILD_TYPE=Release -DTHEOS_BUILD_TESTS=OFF
cmake --build build-wasm                 # writes web/dist/theos.{js,wasm}
web/build-site.sh ./build/theosc site    # needs a native theosc build
python3 -m http.server -d site
```

The `Web` workflow builds and tests all of this and deploys `site/` to GitHub Pages on pushes to `main`
(GitHub Pages must be enabled with "GitHub Actions" as the source in the repository settings).
